## Data and external services (not distributed with Veriqa)

- **MaxMind GeoLite2 databases** are **not** shipped with Veriqa. If you use
  GeoIP features, you download the database yourself and accept MaxMind's own
  EULA. The client library (`MaxMind.GeoIP2`) is Apache-2.0.
- **`Microsoft.Data.SqlClient.SNI.runtime`** (6.0.3, Microsoft Software License Terms — not open source)
  is a dependency of `Microsoft.Data.SqlClient`, which the SQL Server
  provider uses. It holds only native Windows libraries, and **no Veriqa
  artifact contains them**: the packages reference it as a NuGet dependency,
  the Docker image and the Linux archives run the driver's managed
  implementation, and the Windows service archive is built without
  `Microsoft.Data.SqlClient.SNI.dll`. An operator who runs SQL Server on
  Windows downloads the package from nuget.org and accepts its terms
  (INSTALL.md, "SQL Server on Windows").
- Separately running services (PostgreSQL, Redis or Valkey, RabbitMQ, an
  external IdP) are not linked into or distributed with Veriqa; their licenses
  are not part of these notices. Note that the Redis server is
  source-available from version 7.4 on (RSALv2 / SSPLv1, plus AGPLv3 from
  8.0); the `samples/docker-compose` stack therefore runs Valkey (BSD-3-Clause),
  a protocol-compatible fork.
